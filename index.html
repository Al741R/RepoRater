RepoRater: Open-Source Software Repository Diagnostic Utility

Welcome to the official project portfolio for RepoRater—a Single-Page Application (SPA) engineered to evaluate the maintenance health, issue backlog density, and community governance of public GitHub repositories in real time.

Project Description & Established Scope

Category: Custom Developer Diagnostic Utility ("Others" — Specified for IT110 Presentation)

1. The Problem Statement

Developers and IT students frequently integrate third-party open-source libraries into their software without realizing a package is abandoned, unlicensed, or overwhelmed by unresolved bugs. Raw repository pages scatter this telemetry across multiple tabs.

2. Primary Application Goal

RepoRater consolidates critical repository telemetry via the public GitHub REST API using asynchronous JavaScript (async/await and Promise.all) to compute an instant, color-coded Health Grade (A to F).

3. Core Diagnostic Algorithm

Rather than passively displaying JSON fields, the application executes a 100-point weighted evaluation across Maintenance Recency (45 pts), Issue Backlog Density (30 pts), and Legal/Community Governance (25 pts).
